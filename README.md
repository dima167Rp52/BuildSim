# BuildSim

2D engineering sandbox for Android. Build devices from components, decorate the housing, and run simple interactive simulations.

## Build APK

Open the **Actions** tab and run **Build BuildSim APK** (or push a change). The debug APK is uploaded as an artifact named `BuildSim-debug-apk`.

## First version

- Drag components from the parts panel onto the grid.
- Move, rotate, and delete placed parts.
- Pan and zoom the workspace.
- Switch between electronics, mechanisms, pipes, and decoration.
- Run a starter circuit simulation with battery, wires, switch, and lamp.
- Change decorative block color/material and save projects on the device.

This is an early sandbox prototype. Simulation rules will expand in later versions.
